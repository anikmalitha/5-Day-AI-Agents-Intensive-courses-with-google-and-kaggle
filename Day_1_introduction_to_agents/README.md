# Day 1 — From Prompt to Agent Architectures  

Welcome to **Day 1** of the *5‑Day AI Agents Intensive (Google × Kaggle)*.  
This module introduces the foundations of prompt engineering and agent design, guiding you from simple prompt structures to complete agent architectures.  

---

## 📚 What You’ll Learn  

- **Prompt Fundamentals**: Intent, context, constraints, and examples — how to craft reliable prompts.  
- **Mapping Prompts to Actions**: Parsing, templates, and extracting structured instructions to drive tools or APIs.  
- **Action Types & Tooling**: Common actions (API calls, search, file ops, calculators) and how to wrap them as tools.  
- **Agent Design Basics**: Perception → decision → action loop, memory patterns, and simple control flow.  
- **Agent Architectures**: Reactive, deliberative/planning, hierarchical, and tool‑augmented agents — tradeoffs and use cases.  
- **Reasoning Patterns**: Chain‑of‑thought, stepwise decomposition, and planning‑to‑action strategies.  
- **Evaluation & Safety**: Correctness, robustness, latency, cost considerations, and guardrails for unsafe or ambiguous instructions.  
- **Hands‑On Practice**: Apply concepts directly in notebooks and compare approaches.

## 📝 Suggested Exercises  

- Design a prompt that reliably extracts a structured task (e.g., *“extract a date and action”*) and implement a parser.  
- Build a minimal tool wrapper (e.g., calculator or web search simulator) and connect it to a prompt‑driven agent loop.  
- Implement two small agents (reactive vs. deliberative) for the same task and compare outcomes and costs.
