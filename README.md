# 5-Day-AI-Agents-Intensive-courses-with-google-and-kaggle
 
 ---


This repository contains my complete learning journey, source code, and hands‑on projects from the **5‑Day AI Agents Intensive Course**.  
Each day builds progressively — from prompt fundamentals to enterprise‑grade agent deployment — showcasing how AI agents are designed, tested, and scaled in real‑world environments.  

---

## 🚀 Course Overview  

The **5‑Day Intensive** covers:  
- **Day 1** → Prompt Engineering & Agent Architectures  
- **Day 2** → Agent Tools & Interoperability with Model Context Protocol (MCP)  
- **Day 3** → Memory & Sessions (short‑term vs long‑term)  
- **Day 4** → Agent Observability & Evaluation  
- **Day 5** → AgentOps & Enterprise Deployment  

Each module includes **notebooks, exercises, and documentation** to reinforce concepts with practical implementations.

## 🧠 Key Learnings  

- **Prompt Fundamentals** → Structuring prompts for reliable outputs  
- **Agent Architectures** → Reactive, deliberative, hierarchical, tool‑augmented  
- **Tooling** → Custom Python tools, agents as tools, MCP integrations  
- **Memory** → Short‑term sessions vs long‑term knowledge stores  
- **Observability** → Logs, traces, metrics, LangSmith, W&B  
- **Evaluation** → Human‑in‑the‑loop, automated metrics, regression testing  
- **AgentOps** → CI/CD pipelines, safe rollout strategies, enterprise governance  
- **Multi‑Agent Ecosystems** → A2A protocol, registries, interoperability

## 🚀 Getting Started  

1. **Clone the repository**  
```bash
git clone https://github.com/anikmalitha/5-Day-AI-Agents-Intensive-courses-with-google-and-kaggle.git
cd 5-Day-AI-Agents-Intensive
```

2. **Install dependencies**  
```bash
pip install -r requirements.txt
```

3. **Configure API keys**  
- Obtain a **Gemini API key** from *Google AI Studio*.  
- Add it to your environment or Kaggle Secrets (`GOOGLE_API_KEY`).  

4. **Run notebooks**  
- Open in **VS Code**, **Jupyter**, or **Kaggle Notebooks**.  
- Execute cells sequentially (avoid “Run All” to prevent API rate limits).
